# Profile artwork

The SVG headers are original, editable artwork, with light and dark variants.

The three project previews use public demo screenshots from the projects, resized into matching frames:

- [Perlustron](https://github.com/BearHuddleston/perlustron/blob/main/docs/assets/perlustron-demo.png) — sanitized demo session.
- [CodexBar KDE](https://github.com/BearHuddleston/codexbar-kde/blob/master/docs/screenshots/overview.png) — synthetic usage data.
- [SayAhead](https://github.com/BearHuddleston/sayahead/blob/main/docs/images/readme/live-correction.jpg) — simulated call.

Each preview is 840 × 560 pixels. Full screenshots remain available in the linked repositories.
